# Homework Glowup

[English](README.md) | [日本語](README.ja.md)

課題の提出物を準備・点検するためのAgent Skillです。何を確認し、どのような根拠が得られたかを、チェックシートに記録します。

## できること

- 回答、課題の条件、文字数制限、単位、計算結果を確認します。実行可能なコードは、必要に応じて代表的な入力と境界条件で確認します。
- 課題ごとに命名指示と保存済みの非公開ルールを読み、最終ファイルの名前・拡張子・実際の形式を照合します。
- 白背景・黒文字・灰色の網掛けを基本とし、必要な強調には赤を使います。長いレポートでは、番号付きの表・図のキャプションが対象の上に中央揃えで配置されているか確認します。
- AI利用の申告と参考リンクは、課題またはユーザーから求められた場合に用意します。課題にAI利用欄がある場合は、実際の利用内容を正確に記載します。
- 人間の作成者情報を設定・確認し、確認済みの人間の情報を保ちながら、作成者メタデータからAIエージェント名を除きます。
- 文書内とファイルシステム上の更新日時を合わせます。新規課題の文書内作成日時は、厳密な30分差から少しずらし、更新日時のおよそ30分前に設定します。後の編集では既存の作成日時を保持します。この差はメタデータ上の取り決めであり、実際の作業履歴を示すものではありません。
- 確認結果・根拠・未確認事項・該当しない理由を、提出物と分けた作業用チェックシートに記録します。

このスキルは提出物をローカルで準備します。アップロードや公開には別途許可が必要です。

## 使い方

Agent Skillsに対応するクライアントへ、[skills/homework-glowup](skills/homework-glowup)ディレクトリを配置します。課題の準備・点検時に `$homework-glowup` を指定します。

スキルには手順と[Markdown形式のチェックシート](skills/homework-glowup/templates/assignment-checklist.md)が含まれます。文書の編集・描画には、クライアントで利用できる形式別のツールを使います。

非公開の命名ルールは、[SKILL.md](skills/homework-glowup/SKILL.md)の説明に従い、このリポジトリとスキルの配置先の外に保存します。チェックシートは提出ファイルと分けた作業場所へコピーし、実際に行った確認を記録します。
